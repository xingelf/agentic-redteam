No Single Best LLM for Cyber

"Which model is best at offensive security?" has no single answer. Across three public benchmarks, the lead changes hands depending on what you measure, which agent harness wraps the model, and whether reasoning is switched on. This is the fine print behind the leaderboard headline — built only from numbers you can read in the primary papers.

Cybench: the lead changes with what you measure

Forty professional CTF tasks, one structured-bash agent, three ways to score the same runs. Each panel ranks the eight models on its own scale; the top bar is the leader. The leader is a different model in each panel — the paper says so itself.

The harness can move as much as the model

The same two top models, run under four agent scaffolds (Cybench, unguided). Swap the wrapper and the ranking flips: GPT-4o falls to 10% on the pseudoterminal scaffold while Claude 3.5 Sonnet climbs to 20%. The scaffolding does real work.

CyberGym: reasoning mode re-orders the board

A harder task — reproducing 1,507 real-world vulnerabilities end to end. Solid bar is the default run; the dashed mark is the same model with reasoning turned up. Switching on high reasoning lifts GPT-5 from 7.8% to 22.0%, overtaking Claude Sonnet 4. The model name alone does not tell you the score.

CVE-Bench: same model, different framework

Forty real web-application CVEs, one-day setting, with the same backbone model. A single CTF-style agent exploits 2.5%; a hierarchical multi-agent team reaches 13%. Roughly a five-fold swing from the harness, holding the model fixed.

Three public cyber-capability benchmarks: Cybench (CTF solving), CyberGym (real-world vulnerability reproduction), and CVE-Bench (web-application exploitation). They measure different jobs on different task sets, so a percentage in one says nothing about a percentage in another. The point of the series here is not a winner but the fine print: metric, harness, reasoning mode, and benchmark each move the ranking.

Sources are peer-reviewed / arXiv papers, linked on each chart. No vendor self-reports beyond what a paper records, no secondary leaderboard trackers, and no models that could not be verified. No client, target, or engagement data. For education and analysis, not a buying guide.
