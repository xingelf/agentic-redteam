# KEV Dashboard

A self-updating dashboard of the CISA Known Exploited Vulnerabilities (KEV)
catalog — the vulnerabilities being exploited in the wild right now. Shows totals,
additions per month, top vendors, and the newest entries.

Second piece in the **Red Team, Visualized** series.

## How it updates

- `.github/workflows/kev-update.yml` runs daily (06:17 UTC) and on manual dispatch.
- It runs `scripts/build_kev.py`, which fetches the public CISA KEV feed, computes
  aggregates, trims it, and writes `data.json`. The workflow commits `data.json`
  only when it changed.
- On GitHub Pages the page fetches `./data.json` at load, so every visit shows the
  latest committed snapshot. The committed `data.json` also keeps the repo
  self-contained.

The Claude Artifact snapshot is published with `index.html` and `data.json`
together; re-publish to refresh it.

## Files

- `index.html` — the dashboard (self-contained; fetches `./data.json`)
- `data.json` — the current snapshot (regenerated by the workflow)
- built by `../../scripts/build_kev.py`

## Data

Public data only — the [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog). No target, client, or engagement data.
