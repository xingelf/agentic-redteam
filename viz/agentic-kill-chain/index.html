The Agentic Kill-Chain

An autonomous offensive agent runs one loop: gather, find, plan, exploit, hold, take — then repeat with what it learned. The loop is old. What changed is that it now runs cheaply, without a specialist at the keyboard. Walk each stage to see what the agent does, where it gives itself away, and what closes the door.

An illustrative model for authorized testing and defense. Stages map to public MITRE ATT&CK tactics and techniques. No target or engagement data.

Attacker view: what the agent does at each stage.

    Sources: MITRE ATT&CK (tactic and technique IDs), OWASP. Technique mappings are representative, not exhaustive.
